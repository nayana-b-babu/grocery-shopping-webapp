Grocery Shopping Web App

A Flask-based Grocery Shopping Web App that allows users to browse grocery products, manage inventory, add items to the cart, place orders, and track customer purchases through a simple and user-friendly interface.

Features
User login and authentication
Product management
Category management
Inventory management
Browse grocery products
Add products to cart
Remove products from cart
Place customer orders
Order management
Responsive user interface
Setup

Create and activate a virtual environment.

Install dependencies:

pip install -r requirements.txt

Configure the MySQL database.

Run the development server:

python app.py

Open your browser and visit:

http://127.0.0.1:5000/

Notes
The project uses MySQL as the default database.
Products can be added, updated, and removed through the application.
Customers can browse products, add items to the cart, and place orders.
Inventory is managed through the product management module.
Static files and templates are organized using Flask's recommended project structure.
