# Grocery Shopping Web App

A **Flask-based Grocery Shopping Web App** that enables users to browse grocery products, manage inventory, add items to the cart, and place orders through a simple and user-friendly interface.

## Features

- User login and authentication
- Product management
- Category management
- Inventory management
- Browse grocery products
- Add products to cart
- Remove products from cart
- Place customer orders
- Order management
- Responsive user interface

## Setup

Create and activate a virtual environment.

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure the MySQL database.

Run the development server:

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Bootstrap
- MySQL

## Notes

- The project uses **MySQL** as the default database.
- Users can browse grocery products and manage their shopping cart.
- Products can be added, updated, and removed through the product management module.
- Customer orders are stored and managed within the application.
- Static files and templates are organized using Flask's recommended project structure.
